1. CARA CEPAT MENGUBAH PENGATURAN (3 cara)
--------------------------------------------------------------------------------
a) FILE .ENV (permanen, dibaca saat bot start)
     Buka file .env di folder root, ubah nilainya, simpan, restart bot.

b) MENU SETUP INTERAKTIF (sesi ini saja — hilang setelah bot restart)
     Jalankan `python main.py` -> menu muncul -> ketik nomor -> isi nilai.
     Contoh: ketik 3 (Scan Mode) -> ketik 2 (XAU + Pairs) -> enter.

c) DASHBOARD WEB (sebagian setting, persist ke .env)
     `python dashboard.py --serve --port 8765` -> buka http://127.0.0.1:8765/
     Dropdown "Mode Trading" (XAU Only / XAU + Pairs) otomatis persist ke .env
     (efektif setelah bot restart).

2. MODE SCAN: XAU ONLY vs XAU + PAIRS  ← PALING PENTING
--------------------------------------------------------------------------------
TRADING_MODE = xau            # default — cuma trading XAUUSD
TRADING_MODE = xau_pairs      # XAU + 4 pair FX cross (multi-scan)

Di mode xau_pairs, TIAP CANDLE M5 bot scan SEMUA simbol dalam pool sekaligus
(parallel scan, bukan giliran). Masing-masing simbol 1x LLM call:
=> 5 simbol = 5x LLM call per candle M5.

POOL SIMBOL (default):
    [XAUUSD-ECN, EURGBP-ECN, EURJPY-ECN, EURCAD-ECN, GBPJPY-ECN]
      (1)            (2)         (3)         (4)         (5)

DETAIL TIAP PAIR:
--------------------------------------------------------------------------------
 Simbol base    Live (suffix)   Demo (suffix)   Timeframe   Spread hasil scan
--------------------------------------------------------------------------------
 XAUUSD-ECN     XAUUSD-ECNc     XAUUSD-ECN      M5          ~10 pts (≈3% ATR)
 EURGBP-ECN     EURGBP-ECNc     EURGBP-ECN      M5          ~0 pts
 EURJPY-ECN     EURJPY-ECNc     EURJPY-ECN      M5          ~0-1 pts
 EURCAD-ECN     EURCAD-ECNc     EURCAD-ECN      M5          ~4-5 pts
 GBPJPY-ECN     GBPJPY-ECNc     GBPJPY-ECN      M5          ~11 pts
--------------------------------------------------------------------------------
Catatan suffix: tulis nama BASE (tanpa c). Bot auto-correct otomatis:
akun live -> -ECNc, akun demo -> -ECN. Satu config jalan di dua-duanya.

KENAPA 4 PAIR ITU?
- Semua CROSS NON-USD => korelasi rendah dengan XAUUSD.
- Pair yang mengandung USD (EURUSD, GBPUSD, dll) DIBUANG karena gerakannya
  didominasi USD => gerak bersama XAU, tidak ada diversifikasi.
- Spread sehat semua (0-11 pts, < 25% ATR).

CARA GANTI DAFTAR PAIR (env, dipisah koma):
    FX_PAIR_SYMBOLS = EURGBP-ECN,EURJPY-ECN,EURCAD-ECN,GBPJPY-ECN

BATAS JUMLAH SIMBOL:
    MAX_ROTATION_SYMBOLS = 5     # pool dipotong ke N simbol pertama

PERILAKU WEEKEND:
    FX market tutup Sabtu-Minggu -> pool otomatis jatuh ke [XAUUSD-ECN]
    (atau [BTCUSD.c] kalau ENABLE_BTC_ROTATION = True).

RISK AGGREGATE (penting!):
    Max posisi (MAX_OPEN_POSITIONS=6) & daily loss ($50) dihitung LINTAS
    SEMUA simbol (magic filter), bukan per-simbol. 6 posisi bisa tersebar
    misal 2 XAU + 1 EURGBP + 1 EURJPY + 1 EURCAD + 1 GBPJPY.

                                  #   nambah loss streak & excluded dari win rate)

LOT SIZE DIHITUNG OTOMATIS dari equity & SL:
    lot = risk_usd / (SL pts x usd_per_point)
    Urutan: risk-based -> recovery (x0.5) / session (x1.2) multiplier
            -> clamp+round ke volume_step broker
            -> margin safety net (lot turun kalau margin > 50% free)

6. SL/TP RULES (PENTING — 2 MODE)
--------------------------------------------------------------------------------
TP_SL_RULES = ATR-Based           # default (safe)
  - SL/TP dari AI dipakai apa adanya, TAPI trade DITOLAK otomatis kalau:
      SL < max(2x spread, 1.25x ATR)  atau  TP < max(2x spread, 2.5x ATR)
  - R:R 2:1 terhadap volatilitas. Bukan dinaikkan — cari setup yang
    secara alamiah 2R.

TP_SL_RULES = LLM                 # bebas
  - SL/TP sesuai thesis model, satu-satunya floor: SL >= 2x spread
    (anti INVALID_STOPS). Lot dihitung dari SL tsb.
  - Prompt diarahkan: SL 100-350 pts (Gold M5) / 20000-60000 pts (BTC M30),
    larang stop hyper-scalping M1.

Nilai lain:
    DEFAULT_SL_POINTS_XAU = 300     # fallback SL (ATR-Based)
    DEFAULT_TP_POINTS_XAU = 600
    DEFAULT_SL_POINTS_BTC = 50000
    DEFAULT_TP_POINTS_BTC = 100000
